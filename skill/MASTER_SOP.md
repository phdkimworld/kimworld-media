## 1. 전역 공통 원칙
- **전문 용어 병기**: 핵심 금융 지표는 처음 나올 때 쉬운 말과 표준 용어를 함께 쓴다. 예: 현금을 뺀 회사 가치(기업가치·EV), 쌓인 일감(잔여수행의무·RPO), 가운데 값(중앙값).
- **'빚' 금지**: 빛과 헷갈리므로 쓰지 않는다. 부채 또는 차입금으로 쓴다.
- **수급 물량 세 지표**: 증자·락업 해제·SEPA를 분석할 때는 세 가지를 함께 낸다.
  1. 전체 발행주식 대비 비율
  2. 유통주식 대비 비율
  3. 평균 거래량 대비 배수(또는 소진 일수)
- **국면 프레임**: 국면 A·B·C의 한 줄 정의 상자를 처음 나오는 자리에 둔다.
- **통화·숫자**: 아라비아 숫자 + 한글 단위 + 달러/센트로 쓴다. '254억$' 같은 혼합 표기는 쓰지 않는다.

## 2. 채널별 지침

### 2.1 웹 리포트
- 도입부는 역할을 나눈다. 핵심 요약은 3줄 개조식, 짧은 답은 결론 한 문장과 국면 진단이다.
- 훅 문단은 짧은 답 안에 둔다. 목차 아래에 따로 떠 있는 문단을 두지 않는다(v2.3).
- 모바일 표는 3열 이하로 한다.
  - 기록표: '이벤트일 · 공시 내용 | 당일 | N거래일 뒤'. 날짜는 오름차순으로 쓴다.
  - 1부 '지금의 크기' 표: 2열(값 · 근거).
  - 숫자 칸에는 숫자만 쓰고, 설명은 표 아래 ※ 주석으로 뺀다.
- 시나리오는 2×2로 쓴다.
  - 과거 빈도(N번 중 M번)를 먼저 보이고, 가능성은 구간으로 쓴다(높음 35~45% 등).
  - 판정일이 모두 같으면 열 머리에 한 번만 쓴다.
- 체크리스트는 '□' 하나의 형식으로 쓴다.
- 액면병합 종목의 과거 가격은 '(병합 전 기준)'을 붙이거나 금액을 빼고 쓴다.

### 2.2 롱폼 영상·TTS
- '안(案)'을 단독으로 쓰지 않는다. '안건'으로 쓴다.
- 치환 사전:

  | 원래 표현 | 바꿔 쓸 말 |
  | --- | --- |
  | 리포트 N부 | 리포트 N번째 부분 |
  | 국면 B | 두 번째 국면 |
  | 닷새·여드레·열흘·열하루 | N 거래일 |
  | 시가 | 시장 가격 |
  | 1상·2상·3상 | 임상 N단계 |
  | 특허 이의 | 특허 분쟁 |
  | 둔화 | 성장이 느려지는 |
  | 조달이 | 조달 부담이 |
  | 사들일 | 매입할 |
  | ~달러대 | ○ 달러에서 ○ 달러 사이 |

- 가격 읽기:
  - 기본은 소수로 읽는다('오 점 이팔 달러').
  - 소수 두 자리가 같은 숫자(2.22·0.55)는 달러·센트로 읽는다('이 달러 이십이 센트').
- 통계 결론('N번 중 M번')은 영상에서 바로 공개한다. 세부 표만 리포트로 안내한다.

### 2.3 쇼츠
- 대본(한글 독음)과 화면 자막(아라비아 숫자)을 나눈다.
- 자막은 말하는 문장 두 줄로 쓴다. 위 카드와 같은 명사구를 되풀이하지 않는다.
- 장면 1의 배지 숫자는 첫 문장에서 말하는 숫자여야 한다. 첫 문장에서는 법인 접미사를 뺀다('미국 제약사 토닉스는').
- 끝에 무음 0.4초를 둔다. 끝 안내는 투표와 관련 영상으로만 한다.

### 2.4 Threads·X
- 첫 문장에 종목명(티커)을 쓴다.
- 숫자 불릿은 3개, 각 35~40자 이하로 쓴다. 투표 보기가 첫 화면 안에 들어와야 한다.
- 2/2 답글은 리포트 직결 링크로 한다. 주간 투표 결산의 2/2에는 최다 투표 종목 리포트 링크를 넣는다.

### 2.5 인스타그램 카드뉴스
- 오른쪽 위를 비우고 장 번호는 아래로 내린다.
- point 카드에는 비교 상자를 둔다.
- record 카드는 큰 숫자에 방향을 붙이고, 캡션에서 같은 말을 되풀이하지 않는다.
- '높음' 시나리오는 강조한다.
- 마지막 장 안내는 '첫 화면에서 바로 보기'로 한다.
- 캡션 첫 줄은 넘기기·투표를 부른다(45자 이내).

### 2.6 주간 투표 결산
- 투표 수 순으로 정렬한다. 10표 미만은 '소수 표본'으로 표시한다.
- 종목마다 쟁점 한 줄을 붙인다.
- 기간은 '최근 30일 누적'으로 밝힌다. 속어 제목은 쓰지 않는다.
- 상위 4종목은 투표로 건다.
