운영자가 준 지침 원문이다. SKILL.md V6과 충돌하면 이 문서를 따른다. 구현 상태는 맨 끝 "도구 반영 현황"에 적는다.

- 근거: 2026-10-14 LQDA 쇼츠(58초)와 AAVE 롱폼(9분 32초)을 프레임 단위로 분석한 결과.

- 모든 규칙에는 합격 기준이 있다. 업로드 전에 측정하고, 측정값을 전달 메시지에 적는다(맨 끝 "보고 형식").

## A. 롱폼

### A1. 출력 규격을 지킨다

AAVE 영상은 1280×720, 15fps로 나왔다. 스킬 V6은 1920×1080을 요구한다. 15fps에서는 차트 선과 숫자 강조가 끊겨 보인다.

- 최종 MP4는 1920×1080, 30fps, h264 + aac로 출력한다.
- 합성 뒤 다시 인코딩하는 단계가 있다면 해상도와 프레임레이트를 낮추지 않는다.
- 합격 기준: `ffprobe -v error -select_streams v:0 -show_entries stream=width,height,r_frame_rate -of csv=p=0 <영상>` 결과가 `1920,1080,30/1`.

### A2. 첫 화면에 영상의 핵심 질문을 띄운다

AAVE 영상은 0~15초 동안 "2026.04.18 해킹 없는 손실 / 부실채권" 타임라인이 5초 간격으로 채워졌다. 제목 질문("월 수익은 4분의 1로 줄었는데 가격은 왜 넉 달 만에 2.7배가 됐나")은 70초쯤 미드롤 이미지에서 처음 보였다.

- 1문단 첫 슬라이드는 `hero` 레이아웃으로 한다. `lines[0]`(at 0)에 핵심 모순 숫자, `lines[1]`(at 1 이하)에 제목과 같은 질문을 넣는다. `bg`는 `thumb/bg_fx.png`를 쓴다.
- 가격 흐름이 핵심인 종목은 1문단 안에 `chart` 슬라이드로 가격 경로(예: 400,100원 → 92,200원 → 248,900원 → 208,700원)를 보여 준다.
- 과거 사건(예: 4월 18일)은 핵심 질문을 보인 뒤에 꺼낸다. 스킬 V1의 "과거는 현재에 매단다"를 화면에서도 지킨다.
- 합격 기준: 영상 10초 지점 프레임에 제목 질문 또는 핵심 모순 숫자가 보인다.

### A3. 제목만 있는 빈 화면을 만들지 않는다

AAVE 영상에는 제목만 뜨고 본문이 빈 화면이 16번, 모두 합쳐 약 45초 있었다(예: "오늘의 주인공", "안에서 벌어진 싸움", "같은 날 두 가치", "2026.10.14 업비트 종가 208,700원").

원인: 스킬 V6.4에서 "아직 읽지 않은 요소는 자리만 차지하고 보이지 않는다". 그래서 슬라이드의 첫 요소 `at`이 슬라이드 `from`보다 크면, 그 사이 문장 동안 제목만 남는다.

- 모든 슬라이드에서 첫 요소의 `at`을 그 슬라이드의 `from`과 같게 둔다. `quote`는 `at`을 `from`과 같게 둔다.
- 첫 문장에 맞는 요소가 없으면 슬라이드를 나누지 말고 이전 슬라이드를 한 문장 더 유지한다.
- slides.json을 저장하기 전에 아래 점검을 돌려 걸리는 슬라이드가 0개인지 확인한다.

```python
import json
d = json.load(open('slides.json', encoding='utf-8'))
bad = []
for pi, p in enumerate(d['paras'], 1):
    for s in p['slides']:
        f = s.get('from', 0)
        els = s.get('lines') or s.get('stats') or s.get('items') or s.get('points') or []
        ats = [e.get('at', 0) for e in els]
        if s.get('layout') == 'compare':
            ats = [s.get('left', {}).get('at', 0), s.get('right', {}).get('at', 0)]
        if s.get('layout') == 'quote':
            ats = [s.get('at', 0)]
        if ats and min(ats) > f:
            bad.append((pi, s.get('layout'), s.get('title', ''), f, min(ats)))
print(len(bad), bad)
```

- 합격 기준(완성 영상): 아래 명령으로 찾은 "본문이 빈 초"가 2초 이하.

```bash
ffmpeg -v error -i <영상> -vf "fps=1,crop=iw:ih*0.78:0:ih*0.22,scale=64:28,format=gray" -f rawvideo - | python3 -c "
import sys
d=sys.stdin.buffer.read(); n=64*28
print([i for i in range(len(d)//n) if sum(1 for b in d[i*n:(i+1)*n] if b>90)<6])"
```

### A4. 한 화면이 15초 넘게 같은 상태로 머물지 않게 한다

스킬에도 있는 규칙이지만 AAVE 영상에서는 지켜지지 않았다. 134→157초, 184→215초, 302→333초, 548→570초에 화면이 20~30초씩 그대로였다.

- 한 문단이 15초를 넘으면 그 문단의 슬라이드를 둘 이상으로 나누거나, 요소의 `at`을 문장마다 나눠 배치한다.
- 합격 기준: `ffmpeg -i <영상> -vf "select='gt(scene,0.04)',showinfo" -f null -`로 뽑은 전환 시각 사이 간격이 15초를 넘는 곳이 없다(미드롤과 outro 제외).
- (2026-10-15 IOVA) `timeline`·`list`의 작은 항목이 한 문장씩 드러나는 것은 장면 감지에 잡히지 않는다. 한 슬라이드가 15초를 넘으면 `at`을 나누지 말고 문장마다 stat·compare·source·quote처럼 다른 레이아웃으로 슬라이드를 나눈다(같은 레이아웃 연속 금지). 쇼츠도 천천히 그려지는 차트만 있는 구간은 정지로 잡히므로 `draw`를 0.2 안쪽으로 끝내고 다음 요소를 바로 붙인다.

### A5. 화면을 넓게 쓰고 글자를 키운다

AAVE 영상의 단일 카드 장면("$1,530만", "40% 아래", "1,600만 개")은 왼쪽 1/3만 쓰고 나머지가 비었다. 카드 아래 설명 글씨는 720p 기준 11~12px로, 폰에서 읽히지 않았다.

- `stat`에 숫자가 하나뿐이면 `hero`로 바꾸거나, `slide.html`에서 카드 1개일 때 가운데 정렬·확대되도록 템플릿을 고친다(저장소 `tools/slidekit/slide.html`을 고치고 커밋한다).
- 1920×1080 기준 최소 글자 크기: big 숫자 120px, 제목 64px, label·text 40px, note·sub 32px. 이보다 작게 나오면 글자 수를 줄인다.
- 합격 기준: `contact.png`에서 화면 가로의 절반 이상이 비어 있는 장면이 없다.

### A6. 미드롤 화면을 줄인다

AAVE 영상에서는 같은 노란 리포트 카드가 다섯 번, 모두 합쳐 약 70초(전체의 11%) 동안 화면을 덮었다. 같은 화면이 반복되어 광고 구간처럼 보인다.

- 대본 속 안내 다섯 번(스킬 V3)은 그대로 둔다. 화면 처리만 바꾼다.
- 전체 화면 미드롤 이미지는 "맛보기"와 "닫기" 두 번에만 띄운다.
- 나머지 세 번(씨앗, 두 번째 맛보기, 되불러오기)은 슬라이드를 유지한 채 하단 배너(높이 15% 이하, "리포트 링크는 고정 댓글")로 처리한다.
- 구현: slides.json 문단에 `"ad_style":"banner"` 또는 `"full"`을 받도록 `make_slide_video.py`를 고치고 저장소에 커밋한다. 이 기능이 생기기 전까지는 안내 문장을 8초 이내로 줄여 전체 화면 노출 시간을 줄인다.
- 합격 기준: 전체 화면 미드롤 노출 합계 30초 이하. `segments.json`으로 확인한다.

### A7. 금액 표기를 통일한다

AAVE 영상에 "$1,530만", "$490만", "$3.85억", "약 $12.7억"처럼 달러 기호와 만·억 단위가 섞여 나왔다.

- 달러 기호(`$`)는 만·억 단위와 같이 쓰지 않는다. "$1,530만"이 아니라 "1,530만 달러", "$12.7억"이 아니라 "12.7억 달러"로 쓴다. `$205`처럼 단위 없는 금액에만 `$`를 쓴다.
- 가격은 상장 거래소 통화(업비트는 원), 회사·프로토콜의 수익과 가치는 달러로 쓴다. 영상 안에서 같은 종류의 숫자는 통화를 바꾸지 않는다.
- 퍼센트는 화면에서 정수로 쓰고, 하루·두 달처럼 기간을 붙인다.
- 합격 기준: slides.json 전체에 정규식 `\$[\d.,]+\s*(만|억)`이 걸리는 곳이 0개.

### A8. 구조 표지를 크게 보여 준다

AAVE 영상은 단서 3개, 가설 3개, 신호 5개를 다루는데, 진행 표시는 오른쪽 위 작은 `kicker`뿐이었다. 시간 순서도 2026 → 2017 → 2025로 오가서 따라가기 어려웠다.

- 단서와 가설이 시작되는 문단마다 첫 슬라이드를 `quote`로 하고, 첫 줄에 "단서 1/3"처럼 번호와 전체 수를 넣는다. 그 화면은 3초 이내로 둔다.
- 과거로 갈 때는 `timeline` 첫 항목에 현재 시점을 두어 "지금 → 과거" 방향이 보이게 한다.
- 유튜브 설명란에 챕터 타임스탬프(0:00 시작, 각 단서·가설·신호 시작 시각)를 넣는다. 시각은 `segments.json`과 `raw_timing.json`에서 계산한다.

### A9. 실제 자료를 화면에 인용한다

9분 넘게 같은 남색 템플릿에 숫자와 짧은 문구만 나왔다.

- 영상당 3~6번, 실제 자료를 인용 카드로 보여 준다. 대상: 뉴스 헤드라인, 공시 문장, 거버넌스 투표 결과, 법원 판결 요지.
- 카드에는 원문 한 줄(번역 가능), 출처 매체명, 날짜를 적는다. 스킬 V6.4의 금지 사항(사람 얼굴, 실제 로고)은 지킨다. 스크린샷 대신 텍스트로 재현한다.
- 구현: `quote` 레이아웃의 `sub`에 "출처 · 날짜"를 넣어 쓰거나, `slide.html`에 `source` 레이아웃을 추가하고 커밋한다.
- 인용 문장과 날짜는 `events.md`에 출처 링크가 있는 것만 쓴다.

### A10. 엔드 스크린 자리를 비운다

마지막 질문은 바로 앞 문단의 투표 화면(`poll`, SKILL G4)으로 옮겼다. 베팅 표현은 쓰지 않는다.

- `outro` 슬라이드는 마지막 20초 동안 글자를 화면 왼쪽 위 1/3 안에 둔다. 오른쪽과 아래쪽은 유튜브 엔드 스크린 요소(추천 영상, 구독 버튼) 자리로 비운다.
- outro 길이는 20초 이상이어야 엔드 스크린을 붙일 수 있다. 짧으면 마지막 문장 뒤에 배경만 남긴 화면을 늘려 20초를 맞춘다.

## B. 쇼츠

쇼츠는 롱폼 슬라이드를 줄여 넣지 않는다. 9:16 전용으로 다시 설계한다. 출력은 1080×1920, 30fps, 길이 60초 이내.

### B1. 화면 영역

| 영역(위에서부터) | 높이 | 넣는 것 | 금지 |
| --- | --- | --- | --- |
| 상단 여백 | 0~8% | 비움 | 글자 |
| 진행 표시 | 8~15% | 진행 바, "단서 1/3", 티커(작게) | 영상 내내 고정된 큰 제목 |
| 핵심 영역 | 15~55% | 장면의 핵심 숫자·차트 1개(화면 폭 80% 크기) | 16:9 카드 통째 삽입, 한 화면에 숫자 3개 이상 |
| 자막 | 55~70% | 나레이션 자막, 최대 2줄 | 핵심 영역 문구를 그대로 반복 |
| 하단 안전 영역 | 70~100% | 비움 | CTA 버튼, 면책 문구, 자막 |
| 오른쪽 여백 | 오른쪽 15%(높이 45% 아래) | 비움 | 글자, 숫자 |

글자 크기(1080 폭 기준): 핵심 숫자 160px 이상, 장면 제목 72~90px, 자막 64~72px, 보조 라벨 40px 이상.

### B2. 훅(0~3초)

- 0.0초부터 움직이는 화면으로 시작한다(급락 차트가 그려지거나 숫자가 커진다). 정지된 텍스트 카드로 시작하지 않는다.
- 숫자는 하나로 통일한다. LQDA 쇼츠는 제목 띠에 "-57%", 카드에 "-70%"가 동시에 보였다. 하루 변동과 기간 누적 변동을 훅에서 섞지 않는다.
- 나레이션 첫 소리는 0.3초 안에 시작한다. 첫 문장은 8어절 이내로 하고, 인사나 채널 소개는 넣지 않는다.

### B3. 리듬

- 같은 화면이 3초를 넘지 않는다. 58초 영상 기준 시각 변화 20회 이상(LQDA 쇼츠는 8회).
- 정보 장면은 훅과 엔딩을 빼고 6개 이하로 한다.
- 문장 사이 무음은 0.2초 이하로 한다. 전환은 하드컷을 쓴다.
- 효과음은 낙폭·단서 공개에만 3~5개 쓴다. BGM은 나레이션보다 18~20dB 낮게 깐다.

### B4. 엔딩과 루프

- 끝에 무음을 두지 않는다. 마지막 단어 뒤 0.3초 안에 끝낸다(LQDA 쇼츠는 1.7초 무음).
- 마지막 장면을 첫 장면과 같은 배경·색으로 맞춰 루프가 이어지게 한다.
- CTA는 마지막 3초에만 화면 높이 40~60% 사이에 넣는다. 문구는 "판결문 해석은 고정 댓글"처럼 받을 것을 구체적으로 쓴다. 화면 속 URL은 눌리지 않으므로 도메인만 띄우지 않는다.
- 면책 문구 전문은 설명란 첫 줄과 고정 댓글에 넣는다. 화면에는 첫 2초와 마지막 3초에만 높이 65% 근처에 작게(36~40px) 넣는다.

### B5. 표기

- 롱폼 A7과 같다. 예: "$2억 2,270만" → "2.2억 달러", "$3억 8,070만 vs $3억 9,610만" → "합의금 3.8억 달러 ≈ 보유 현금 4.0억 달러".
- 법률·영어 용어는 쉬운 말로 바꾼다. 예: "특허 청구항 2개 유효·침해" → "법원: 경쟁사 특허를 침해했다".

### B6. 58초 구성 틀

| 구간 | 역할 | 화면 |
| --- | --- | --- |
| 0~3초 | 훅 | 급락 차트 → 핵심 숫자 확대 → 답의 단서 0.5초 |
| 3~10초 | 모순 | 좋은 소식 숫자 → "그런데" → 반대 방향 숫자 |
| 10~20초 | 단서 1 | 결정적 사건, 핵심 문장 강조 |
| 20~28초 | 결과 | 가격 카운트다운, 낙폭 도장 |
| 28~40초 | 단서 2 | 인물·금액 비교 |

## C. 업로드 전 검증

아래 항목 중 하나라도 걸리면 고친 뒤 다시 합성한다. 스킬 V7의 업로드 조건(6장 점검 통과)에 이 항목들을 더한다.

롱폼
- [ ] 1920×1080, 30fps, h264 + aac
- [ ] 10초 지점 프레임에 제목 질문 또는 핵심 모순 숫자가 있다
- [ ] slides.json 빈 화면 점검 0개, 완성 영상의 본문이 빈 초 2초 이하
- [ ] 화면 전환 간격 15초 초과 0곳(미드롤·outro 제외)
- [ ] 전체 화면 미드롤 노출 합계 30초 이하
- [ ] `\$[\d.,]+\s*(만|억)` 표기 0개
- [ ] 설명란에 챕터 타임스탬프가 있다
- [ ] outro 20초 이상, 오른쪽·아래쪽이 비어 있다

쇼츠
- [ ] 1080×1920, 30fps, 60초 이내
- [ ] 하단 30%와 오른쪽 15%에 글자·버튼이 없다
- [ ] 영상 내내 고정된 제목 띠·CTA·면책 문구가 없다
- [ ] 훅 화면의 숫자가 서로 일치한다
- [ ] 3초를 넘는 정지 화면이 없다
- [ ] 끝 무음이 0.3초 이하이다

## 도구 반영 현황 (2026-10-15)

- A1: `make_slide_video.py` 출력 30fps(이전 15fps).
- A3·A7: `check_slides.py`가 첫 요소 at>from(BLANK), `$+만/억`(MONEY), 번호 배지 3자 이상(BADGE)을 실패로 처리한다.
- A5: `slide.html`에서 stat 카드가 1개면 가운데 크게 그린다. 글자 자동 축소 하한은 40px이다.
- A6: 문단 `ad_style`("full"|"banner")을 지원한다. 지정이 없으면 두 번째와 마지막 안내 문단만 전체 화면이고, 나머지는 하단 150px 배너다(slides.json 최상위 `banner`로 문구를 바꿀 수 있다).
- A9: `source` 레이아웃(`kind`, `orig` 원문 한 줄, `tr` 번역, `src` 매체, `date`, `at`)이 있다.
- A10: outro 글자는 왼쪽 위 860×560px 안에 둔다. 마지막 문단이 20초보다 짧으면 마지막 화면을 늘려 20초를 맞춘다.
- C: `kimworld-media/tools/video_check.py long|shorts`가 측정값과 보고 한 줄을 낸다. 10초 프레임(check_10s.png)은 눈으로 확인한다.
- 쇼츠 B: `tools/shorts/make_shorts.py`는 아직 B1~B6 전면 재설계 전이다. 검증(video_check.py shorts)으로 정지 3초·끝 무음·안전 영역을 잡고, 걸리면 장면을 쪼개 다시 렌더한다.
