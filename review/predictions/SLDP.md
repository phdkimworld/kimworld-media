# SLDP (솔리드파워) 예측 통찰

시나리오 쓰기 전: `python3 tools/pred_ledger.py --judge --report --ticker SLDP` → 이 파일 → [통합 통찰](README.md). 숫자는 장부(ledger.jsonl)·사이트 채점표·나스닥 종가에 있는 것만 쓴다.

## 다음 예측 때 쓸 규칙
1. 현금선(한 주당 유동성) 아래로 가는 쪽을 높게 둔다. 1.84달러 아래(40%)와 현금선 이탈 두 갈래(합 65%) 모두 맞았다.
2. 실적 첫 반응 범위를 과거 범위로만 잡지 않는다. 과거 -19.2%~+6.8%로 봤는데 +10.8%였다(현금 투입 전망 하향 소식). 범위 밖 갈래를 하나 둔다.
3. 첫날 상승은 하루로 끝났다. 첫날 방향과 20거래일 뒤 방향을 따로 건다.
4. 무증자 진단은 두 번 맞았다(발행 공시 0건). 증자 갈래는 계기(새 계약·가격 급등)가 없으면 낮게.
