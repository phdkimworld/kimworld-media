## F2. TNXP 롱폼(O8temUyKQE4) 검토 → 오디오·발음 지침 v2.4 제안

잘 반영된 것(유지): 병합 전 공모가를 대본에서 '할인된 가격으로 새 주식을 팔았고'로 치환, '차입금은 없고', 기록 결론 먼저 공개, 네 번째 시나리오 브리지 문장.

고칠 것(대본·TTS 전처리 지침과 script_audio_check 검사로):
1. 임상 단계: '이상 임상'(2상)이 '이상(異常)'으로, '삼상 임상'이 '참상'처럼 들림 → 대본에서 1상·2상·3상 금지, '임상 2단계'·'세 번째 단계 임상'으로.
2. '이의'(특허 이의)가 '2위'로 들림 → '특허 분쟁'·'특허에 제동을 걸고' 등으로.
3. '십일 달러에서 십사 달러대였습니다'가 '십사 달러 되었습니다'로 들림 → '~달러대' 금지, '십일 달러에서 십오 달러 사이'.
4. 'X 달러 Y 센트'가 자막에서 'cm'로 잡히거나 '센트'가 빠진 것처럼 들림('오 달러 십삼는') → 운영자 제안은 '오 점 일삼 달러' 소수점 읽기. 채널 기존 규칙(달러·센트)과 충돌하므로 ASR로 두 방식을 비교한 뒤 정한다.
5. 어휘 치환: '모자랄까요'→'부족할까요', '사들일 수 있는 한도'→'자사주를 매입할 수 있는 한도'('사드릴'로 들림), '조달이 누를지'→'자금 조달이 주가를 누를지'('조달리'로 연음).
6. 소수점 뒷자리 중복('사십오 점 팔 퍼센트가 팔 퍼센트가', '구 점 이 배가 이 배가')이 들린다는 지적 → narration.txt에는 중복 없음. 운영자가 본 자막·요약 도구의 인식 결과일 수 있으니 raw.wav 해당 구간(01:43, 03:11)을 ASR로 다시 확인하고, 실제 음성 중복이면 TTS 전처리 치환을 숫자 전체 매칭으로 고친다.

검수 체크리스트 추가분(v2.4): 임상 단계 풀어 쓰기 / '이의' 없음 / '~달러대' 없음, 가격 읽기 방식 통일 / 소수점 중복 낭독 없음 / '모자랄'·'사들일' 없음.

## F3. TNXP 쇼츠(ppSAU0HinmQ) 검토 → 쇼츠 지침 v2.5 제안

고칠 것(shorts_check 검사로):
1. 위 카드·스탬프와 아래 자막의 같은 문구 반복: 장면 2(9월 말 현금 1억 6,280만 달러), 장면 3(시가총액 9,060만 달러), 장면 5(분기 유출 4,200만 달러), 장면 7(스탬프 '허가 날 -36.3%' 바로 밑 자막 '허가 날은 -36.3%') → 아래 자막은 말하는 문장(아라비아 숫자)으로 쓰거나, 스탬프에는 보충 사실을 넣는다(예: 허가 당일 반응. 리포트에 있는 숫자만). 검사: 카드·스탬프 글과 자막의 숫자+명사 중복을 잡는다.
